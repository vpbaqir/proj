# SkillLoop smoke-test checklist

- [ ] App loads and the Discover view is usable on a narrow phone and wide desktop.
- [ ] Search by a skill/person filters cards; clear search returns the original list.
- [ ] Category tabs and sort options alter the card list.
- [ ] Bookmark toggles; Saved skills reflects the chosen IDs.
- [ ] Personalized matches can be switched on and off.
- [ ] Offer a skill validates the name and inserts a new card.
- [ ] Request exchange creates a pending item in My sessions.
- [ ] Profile edits update the profile and offer/learn labels.
- [ ] Guild join toggles membership in card/details.
- [ ] Send message rejects empty input and appends typed messages.
- [ ] Modal closes with X, backdrop click, and cancel where available.
- [ ] Keyboard focus is visible and reduced motion is respected.
- [ ] \`npm run build\` completes successfully.
